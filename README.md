# Enterprise Cloud DevOps Platform

Enterprise-style Cloud, DevOps and Platform Engineering portfolio project.

## Objectives

- Linux and Bash automation
- Git and GitHub
- Terraform Infrastructure as Code
- Docker containerization
- Kubernetes
- Azure Kubernetes Service (AKS)
- Red Hat OpenShift
- GitHub Actions
- Azure DevOps
- Azure Container Registry
- Azure Storage / ADLS Gen2
- Azure Databricks
- Azure Key Vault
- Azure Monitor
- AWS cloud integration
- Enterprise troubleshooting and operational runbooks

## Architecture

The platform will demonstrate an end-to-end application and
data platform deployed across Azure AKS and Red Hat OpenShift.

## Environments

- Development
- Test
- Production

## Engineering Principles

- Infrastructure as Code
- Git-based change management
- Automated CI/CD
- Secure identity and secrets management
- Containerized workloads
- Kubernetes-native deployment
- Automated testing
- Monitoring and observability
- Operational troubleshooting
- Documented recovery procedures
